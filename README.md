# Pyodide File Saver for Open WebUI

Save files generated by browser Python into Open WebUI, with downloadable links
in the assistant's answer and a saved workspace for later edits.

**Experimental pre-release.** Compatibility is checked against the host's actual
APIs and database contracts, not an exact version label. The installer minimum
is not a promise that every newer release or fork works. See the scoped
[compatibility and qualification matrix](docs/dev/compatibility.md) for exact-artifact
browser observations and their limits. Start with synthetic files on a
non-production instance.

## What it does

- Runs agent-invoked Python in the browser, not on an execution server.
- Saves a private workspace checkpoint, including files written before an
  ordinary Python exception, when transfer and storage succeed.
- Publishes newly created or byte-changed files from `outputs/` as native Open
  WebUI attachments and returns Markdown download links for the answer.
- Restores acknowledged workspace files when the next execution starts,
  including from a fresh authenticated browser.

Open WebUI remains responsible for authentication, sharing permissions, storage
and downloads. No separate service, frontend patch or custom HTTP route is added.
The Tool creates two small coordination tables in Open WebUI's existing database.

## Quick start

Build with Python 3.11 or newer. Building uses only the Python standard library; installing
the development environment into Open WebUI is unnecessary.

```sh
git clone https://github.com/vzd3v/openwebui-pyodide-file-saver.git
cd openwebui-pyodide-file-saver
python3 scripts/build_tool.py --check
```

Paste `dist/openwebui_pyodide_file_saver.py` into a new native Tool under
**Workspace → Tools**. Enable it for a test chat/model using native function
calling and the Pyodide engine. Read the [installation guide](docs/ops/install.md)
before enabling it; keep existing browser persistence enabled.

Ask for a document normally. The agent writes issued files under `outputs/`;
the Tool saves them automatically and returns Markdown download links for the
answer. Other files are private workspace recovery material, not shared results.

## Scope and limitations

Saving is part of the selected Tool's execution, not a second publication call.
Installing it does **not** intercept manual code blocks, import old browser files
or back up the browser's entire filesystem. Python variables and installed
packages are not checkpointed.

Downloads use authenticated Open WebUI routes, not anonymous or expiring public
URLs. Qualification applies only to the artifact/host/provider matrix linked above. Browser
code is not isolated from other code in the same Pyodide runtime. Saved files are
not automatically pruned; owners can delete them through normal host controls.

Read the [user guide](docs/user/guide.md), [security limits](SECURITY.md),
[architecture](docs/dev/architecture.md) and [testing guide](docs/dev/testing.md).
