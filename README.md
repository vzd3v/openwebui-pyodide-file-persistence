# Pyodide File Saver for Open WebUI

Save files generated by agent-run Python to Open WebUI storage, with workspace
recovery and shared-chat downloads.

**Pre-release.** The adapter targets Open WebUI 0.12.2. Real-browser, sharing
and storage-provider qualification is pending; no supported release or verified
compatibility matrix is available yet.

## Quick start

```sh
uv sync --locked
uv run python scripts/build_tool.py --check
```

Paste `dist/openwebui_pyodide_file_saver.py` into a new native Tool under
**Workspace → Tools**. Enable it for a test chat/model using native function
calling and the Pyodide engine. Read the [installation guide](docs/ops/install.md)
first: two small tables are created in Open WebUI's existing database; no
separate server or executor is added.

Ask for a document normally. The agent writes issued files under `outputs/`;
the Tool saves them automatically and returns Markdown download links for the
answer. Other files are private workspace recovery material, not shared results.

## Goal

Save generated files into Open WebUI's configured storage, associate published
outputs with their chat messages, and restore saved work for subsequent agent
executions. Download and sharing permissions remain with Open WebUI.

Saving must be part of execution, not a second command the model may omit.
Do not turn off existing browser persistence until server saving, restoration
and migration have been verified. Installation must not silently change the
host application's persistence settings.

## Scope

The initial direction is a native Tool for agent-invoked Python execution,
without a separate execution server. Manual code-block execution and universal
browser filesystem autosave are not automatically covered by installing a Tool.

Read the [user guide](docs/user/guide.md), [security limits](SECURITY.md),
[architecture](docs/dev/architecture.md) and [testing guide](docs/dev/testing.md).
